CreamClient v1.0

Визуальный, косметический, HUD и оптимизационный клиент для Minecraft Forge Visual, Cosmetic, HUD & Optimization Client for Minecraft Forge
1.16.5 (Java 8) • 1.21.4 (Java 21)

Возможности Features

  • Панель управления (Right Shift) — 11 вкладок, глобальный поиск по модулям, переключатель RU/EN, биндер клавиш, плавная прокрутка glScissor, звуки интерфейса SoundFX.
  • Control Panel (Right Shift) — 11 tabs, global search across modules, RU/EN toggle, per-module keybinder, glScissor smooth scrolling, SoundFX UI sounds.
  • 100 уникальных 3D-косметик — ушки, рога, короны, визоры, шляпы мага, крылья, катаны, плащи, джетпаки, дроны, кристаллы, Сатурн, пентаграммы, ДНК-спирали и частицы.
  • 100 Unique 3D Cosmetics — ears, horns, crowns, visors, wizard hats, wings, katanas, capes, jetpacks, drones, crystals, Saturn, pentagrams, DNA helices & particles.
  • Бой и рука — SmoothSwing (5 стилей удара), HandVisuals (сдвиг X/Y/Z, поворот, масштаб), HitParticles, HitShockwave, DamagePopups.
  • Combat & Hand — SmoothSwing (5 swing styles), HandVisuals (X/Y/Z offset, rotation, scale), HitParticles, HitShockwave, DamagePopups.
  • Мир и небо — CustomSky (20 стилей), Дыхание блока (2с), Лужа под дождём (5с), 2D мазок от стрел (200мс), Мини-погода, FreeLook (Left Alt).
  • World & Sky — CustomSky (20 styles), BlockBreathe (2s), RainPuddle (5s), Projectile2DTrail (200ms), WeatherMiniOrb, FreeLook (Left Alt).
  • Метки и радар — 3D-метки на M, авто-метка смерти DeathCoords, радар игроков (150м) с уведомлениями и звуком.
  • Waypoints & Radar — 3D beacon waypoints on M, automatic DeathCoords, player radar (150m) with toast & sound alerts.
  • Плеер и ресурс-паки — .wav плеер с перемоткой (-10s/+10s, F7/F8/F9), конвертер MP4 → WAV, мгновенная перезагрузка ресурс-паков.
  • Music & Resource Packs — seekable .wav player (-10s/+10s, F7/F8/F9), MP4 → WAV converter, instant resource pack reload.
  • Оптимизация (Картошка) — дальность чанков 2-16, дальность мобов 50%-100%, частицы, графика, мягкий свет, облака, мипмапы, лимит FPS.
  • PotatoOptimizer — render distance 2-16, entity distance 50%-100%, particles, graphics, smooth lighting, clouds, mipmaps, FPS cap.
  • Конструктор HUD — перетаскивание, масштаб 0.50x-2.20x, сдвиг по 1px, смена стиля всех 9 виджетов; свои #HEX/RGB цвета и .json профили.
  • HUD Constructor — drag, resize 0.50x-2.20x, 1px nudge, restyle all 9 HUD widgets; custom #HEX/RGB colors & .json profiles.

Сборка Build

Нужна Java 8 для 1.16.5 и Java 21 для 1.21.4.

Requires Java 8 for 1.16.5 and Java 21 for 1.21.4.

# Forge 1.16.5 (Java 8, Gradle 7.4.2)
gradle build --no-daemon --stacktrace

# Forge 1.21.4 (Java 21, Gradle 8.10.2)
cd port-1.21.4
gradle build --no-daemon --stacktrace
